# 常见问题

按主题分组。如果你的问题不在下表里，欢迎到工单或社区提问。

## 账户与套餐

**Q：注册需要邀请码吗？**

A：不需要。任何邮箱都可以注册并进入 Trial 套餐。如果你有 [Beta 邀请码](./beta-program.md)，注册时填上即可直接成为 Beta 用户。

**Q：我注册成 Trial 了，能用邀请码升级到 Beta 吗？**

A：目前不支持注册后补填。请联系管理员手动调整。

**Q：能用一个邮箱注册多个账户绕过限速吗？**

A：技术上能创建，但属于违反服务条款。多次违规账户会被合并冻结，钱包余额也会被清算。

**Q：我能转账积分给另一个账户吗？**

A：暂不支持账户间直接转账。可以通过分享邀请码实现"邀请奖励 → 钱包"路径。

## API & 接入

**Q：你们兼容 OpenAI SDK 吗？**

A：兼容。把 `base_url` 指向你的 AIKanHub 地址即可。但视频生成的端点是 `/v1/video/generations`，参数与 OpenAI 不完全一致 —— 详见 [API 参考](./api-video-generation.md)。

**Q：可以用 Anthropic / Gemini 风格的请求体吗？**

A：AIKanHub 内核是多协议网关，对话类模型支持 OpenAI / Anthropic / Gemini 三种入口；视频生成目前仅暴露 OpenAI 风格接口。

**Q：流式响应（SSE / WebSocket）支持吗？**

A：对话模型支持流式。视频生成是异步任务，没有流式概念 —— 用轮询 `GET /v1/tasks/{id}` 拿状态。

**Q：我能在自己的服务端直接代理你们的 API 吗？**

A：可以。`sk-xxx` Token 只对你的账户有效，怎么用是你的自由。但如果出现明显的二次转售行为（向第三方收费提供 API），可能违反服务条款。

## 计费

**Q：1 积分 = $0.01 是不是固定汇率？**

A：是的，恒定换算。详见 [Billing & Credits](./billing.md)。

**Q：失败任务退款多久到账？**

A：失败状态确定后约 1–2 秒内退到钱包。如果几分钟还没看到退款，请提交工单。

**Q：我充错了能不能退款？**

A：未消费的充值在 7 天内可以原路退款（手续费由我们承担）。超过 7 天或已部分消费的，原路退款剩余部分但扣 5% 手续费。

**Q：充值能开发票吗？**

A：Stripe 自动发邮件收据。需公司抬头发票请充值后联系客服。

## 速率与并发

**Q：429 会扣我钱包吗？**

A：不会。请求被拒绝时不预扣额度。

**Q：Trial 速率太低，能临时调高吗？**

A：升级 Beta 或 Paid 即可。我们不为 Trial 提供临时调高（保护后端公平性）。

**Q：你们有最大并发限制吗？**

A：有平台级公平使用上限，远高于任何单套餐速率，正常使用感知不到。详见 [Rate Limits](./rate-limits.md)。

## 数据与安全

**Q：你们会保存我生成的视频吗？**

A：生成后的 `video_url` 是平台缓存的临时链接，约 2 小时过期。我们不长期保留你的输出文件，请尽快下载到自己存储。

**Q：你们会把我的 prompt 用于模型训练吗？**

A：不会。AIKanHub 只是网关，不训练任何模型。但请注意你的 prompt 会传给后端模型供应商执行 —— 不要在 prompt 里塞敏感数据（个人证件号、API Key、商业机密等）。

**Q：日志保留多久？**

A：调用日志默认保留 90 天用于故障排查和计费对账，之后自动清理。生成的视频文件保留 ~2 小时。

**Q：能本地化部署吗？**

A：AIKanHub 本身是开源网关，可以自托管。商业 / 受管版本另有 SLA，欢迎联系销售。

## 故障排查

**Q：返回 "no available channel"。**

A：当前套餐没有这个模型的访问权。换 Lite 系列模型或升级套餐。详见 [Pricing](./pricing.md)。

**Q：返回 5xx 但已经扣了费。**

A：5xx 通常意味着任务进了排队但后端处理失败。系统会在几秒内自动把任务标为 `failed` 并退款。如果余额没退，请提交工单附上 `task_id`。

**Q：视频 URL 打不开 / 404。**

A：URL 是短时效的（约 2 小时）。如果你需要重跑同一个 prompt，请重新提交任务（成本相同）。

**Q：模型生成结果不符合预期 / 质量差。**

A：模型本身的输出我们不能直接调优。建议尝试：
- 换更高档位的模型（Lite → Pro）。
- 优化 prompt（具体场景描述、加入风格关键词）。
- 调整时长（短视频通常质量更稳）。
