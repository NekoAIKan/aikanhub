# 常见问题

## credits 是什么？

credits 是平台展示给用户的统一余额单位。不同模型和任务会折算为 credits 消耗，用户不需要理解内部换算。

## 为什么我的注册需要邀请码？

管理员可能开启了活动邀请码门槛。此时必须输入有效的活动邀请码才能注册；个人邀请关系不能替代活动邀请码。详情见 [Beta 计划](beta-program.md)。

## starter token 为什么不能调用某些模型？

starter token 可能被设置了模型范围或到期时间。请检查令牌页面中的限制，再确认账号分组是否允许访问目标模型。相关说明见 [快速开始](getting-started.md) 和 [计费说明](billing.md)。

## 为什么请求被限流？

可能是请求过于密集、并发任务过多、模型临时拥挤或分组策略限制。建议降低并发并延迟重试。详情见 [速率限制](rate-limits.md)。

## 如何估算成本？

先根据使用场景选择套餐，再在小规模调用中观察账单记录。平台会用 credits 展示消耗，便于持续评估。详情见 [价格与套餐](pricing.md)。

## 视频任务失败会怎样？

失败任务会返回错误状态和原因。credits 是否扣减取决于站点的结算规则和任务进度，最终以账单记录为准。接口说明见 [视频生成 API](api-video-generation.md)。

## 还应该阅读哪些页面？

建议从 [产品文档首页](README.md) 开始，再按需要阅读 [快速开始](getting-started.md)、[计费说明](billing.md) 和 [速率限制](rate-limits.md)。
