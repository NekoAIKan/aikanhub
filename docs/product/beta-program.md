# Beta 计划

Beta 计划用于邀请小范围用户体验新模型、新计费策略或新产品能力。管理员可以通过活动邀请码控制准入，并为参与用户设置专属分组和初始 credits。

## 加入方式

如果站点开启活动邀请码门槛，注册时必须输入有效的活动邀请码。活动邀请码可以带有专属 credits、默认分组和使用次数限制。过期、停用或已用尽的活动码无法继续注册。

## 参与者须知

Beta 功能可能调整较快，接口行为、可用模型和展示字段都可能随版本变化。请把重要业务放在可回滚路径上，并在控制台关注账单、限流和错误记录。

## 反馈内容

提交反馈时建议包含：账号名、请求时间、请求 ID、使用模型、期望行为和实际结果。不要在反馈中粘贴完整令牌或敏感业务数据。
