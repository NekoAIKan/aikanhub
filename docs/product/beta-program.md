# Beta 测试计划

Beta 是 AIKanHub 的邀请制测试通道。受邀用户可解锁 **全量视频模型**（含 1080p 与 Pro 系列）和 **更高的速率上限**，并获赠等额于 $200 的初始积分。

## 谁适合申请

- 有真实视频生成场景，希望在公开发布前先跑通流程的开发者 / 工作室。
- 希望参与产品反馈、能接受偶发 API 变更的早期用户。
- 已经在 Trial 上验证过基础能力、需要更高分辨率和吞吐的用户。

## 怎么获得邀请码

目前 Beta 是**完全人工审批**。请通过以下任一方式联系我们：

- 邮件：填写你的使用场景与预期月用量。
- Twitter / X：私信。
- 已有 Beta 用户也可以分享他们的邀请码（每个 Beta 账户都有自己的 `aff_code`，传播是允许的；但每个邀请码使用次数会受到管理员配置的上限约束）。

## 用邀请码注册

1. 在注册页找到"邀请码 (Invitation / Aff Code)"字段。
2. 粘贴你拿到的邀请码（格式类似 `aff_xxxxxxxx`）。
3. 完成邮箱验证。
4. 登录后你会发现：
   - 钱包额度已自动设置为 Beta 起始额度（约 20,000 积分 ≈ $200）。
   - 你的账户组别为 `beta`，可调用全量视频模型。
   - 邀请你的人也会收到一笔邀请奖励积分。

> 已经注册成 Trial 的用户能否补填邀请码升级到 Beta？目前**不行** —— 邀请码只能在注册时使用一次。如有特殊情况请联系管理员手动调整。

## Beta 与 Trial / Paid 的对比

| 维度 | Trial | Beta | Paid |
| --- | --- | --- | --- |
| 起始钱包 | ≈ $20 | ≈ $200 | 按充值 |
| Lite 模型（720p 文/图生视频） | ✅ | ✅ | ✅ |
| Pro 模型 / 1080p | ❌ | ✅ | ✅ |
| 速率（每分钟成功任务） | ~20 | ~40 | ~200 |
| 升级方式 | 充值进 Paid | 用完后充值进 Paid | — |
| API 是否会有破坏性变更 | 极少 | 偶发，会提前通知 | 极少 |

## Beta 用户的权利与义务

**权利**

- 优先访问新模型与新功能。
- 直连产品团队的反馈渠道。
- 邀请奖励：成功邀请新 Beta 用户后，你会获得一笔邀请奖励积分。

**义务**

- 不要将 Beta 邀请码用于商业转售。
- 在我们因接口变更通知你时，请配合升级你的客户端代码。
- 滥用（脚本批量薅、对外提供白嫖代理等）会被取消 Beta 资格并冻结账户。

## 用完 Beta 额度之后怎么办

- 直接在控制台充值。Beta 用户充值后会自动转为 **Paid 套餐**，权限和速率会进一步上调（详见 [Pricing](./pricing.md)）。
- 模型权限继承下来，已生成的历史记录不变。

## 邀请奖励规则

- 当被邀请人成功注册并通过邮箱验证后，邀请人立即获得邀请奖励积分。
- 奖励积分进入邀请人的"邀请额度 (Aff Quota)"账户，可在控制台查看。
- 邀请额度可用于充值钱包，但不计入历史钱包总值（用于风控统计）。

## 常见问题

**Q：我能拿到自己的邀请码去邀请别人吗？**

A：可以。登录后到 **个人中心 → 推广**（或调用 `GET /api/user/aff`）即可获取你的邀请码。但请注意：通过你的邀请码注册的用户**会以你的组别为准** —— 即如果你是 Beta，他们也会自动是 Beta；如果你是 Trial，他们也是 Trial。

**Q：Beta 期间会有 SLA 吗？**

A：Beta 期间不承诺 SLA，但实际 uptime 与 Paid 共用同一基础设施。如遇较大停机，我们会在状态页和邮件通知。

**Q：Beta 会一直存在吗？**

A：随产品成熟，Beta 通道可能会调整起始额度或合并入 Paid 的免费额度。已发出的邀请码在公告调整窗口内仍然有效。
