# 计费说明

计费系统把不同模型和任务统一折算为 credits。用户侧账单以 credits 展示，便于跨模型、跨任务类型比较成本。

## 扣费时机

普通请求通常会在请求开始前预留一部分 credits，并在请求完成后按实际结果结算。若请求失败、被拦截或未产生有效结果，系统会按后台规则处理释放或回滚。

视频、图像、音频等任务可能按任务状态、输出结果或专门的计费规则结算。最终以账单记录中的消耗为准。

## 账单记录

账单记录会显示请求时间、调用模型、消耗 credits、请求状态和可见的统计信息。管理员可能根据站点策略隐藏部分内部成本字段，但用户仍能看到与余额相关的关键结果。

## 分组与令牌

用户分组会影响可用模型、价格策略和限流策略。令牌也可能带有单独的模型范围或到期时间。若某个令牌无法调用特定模型，请先检查令牌限制，再检查账号分组。
