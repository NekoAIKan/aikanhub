## 推荐阅读顺序

第一次使用时，先读 [快速开始](getting-started.md)，确认账号、令牌和模型调用流程。准备上线或对接业务前，再读 [价格与套餐](pricing.md)、[计费说明](billing.md) 和 [速率限制](rate-limits.md)。如果你正在参加内测，请同时阅读 [Beta 计划](beta-program.md)。

## 相关约定

- credits 是用户侧展示和沟通的唯一余额单位。
- 管理后台可以配置注册赠送、活动邀请码、令牌策略和分组权限。
- API 文档中的模型 ID 仅用于请求示例或参数表，不代表页面正文中的供应商介绍。
